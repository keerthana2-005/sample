CSS: Static vs Inline

Static CSS

Static CSS is written in separate `.css` files and linked using the `` tag in the HTML head. It is reusable and cleaner for larger projects.

<link rel="stylesheet" href="style.css">

Inline CSS

Inline CSS is applied directly on the HTML element using the `style` attribute. It's useful for quick styling but not recommended for large projects.

<div style="color: red; font-size: 20px;">Hello</div>
